# Dhinchak Dabba

A desi beat-making toy. Drop sounds onto a seven-player folk-art band, find the secret combos, share your mix.
Two packs: Hinglish (Dhinchak Dabba) and Tamil (Dabba Kuthu). Every sound is synthesised live with the Web Audio API, so there are no audio files.

Single static page: `index.html`. Deployed on Vercel with Web Analytics.
